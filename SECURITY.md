# Security Policy

## Supported Versions

Security fixes are provided for the latest version on the `main` branch.

| Version | Supported |
| ------- | --------- |
| Latest `main` | Yes |

## Reporting a Vulnerability

Please do not report suspected vulnerabilities through public GitHub issues.

Report security concerns privately by emailing the repository owner or by using GitHub's private vulnerability-reporting feature if it is enabled for this repository.

Include, where possible:

- A clear description of the issue
- Affected version or commit
- Steps to reproduce the issue
- Expected and actual behavior
- Potential impact
- Suggested remediation, if known

You should receive an acknowledgement within 7 days. We will investigate the report, work on a fix where appropriate, and coordinate disclosure after a fix is available.

## Scope

Web Security Checker is intended for passive inspection of websites and systems you own or are explicitly authorized to test. It is not designed for exploitation, active scanning, or penetration testing.
